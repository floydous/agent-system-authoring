## Execution Metadata & Key Discovery

- **Target Model**: `GPT 6 Luna` *(Phase A and B `.jsonl` logs preserve raw API payloads; Phase C `results_PC-1.jsonl`/`results_PC-2.jsonl` omitted `model`/`request_payload` in v1.1.0, fixed in `phase_c_harness.py` and Eval Suite v3 `results_evals_v3.jsonl`)*
- **Unit-of-Analysis Policy**: Zero pseudoreplication — repeated iterations (`N = 5`/prompt) are aggregated into prompt means (`df = P - 1`) before paired *t* or exact sign testing. Pooled run counts and `TARa@5` are reported descriptively.
- **Phase A (`raw/`)**: `228` completions (`reasoning_effort: xhigh`, `N = 1` run/prompt). Revealed a latent prompt-wording defect in `SP-4` (`4/12` `c5_severity`), ceiling effects in `SP-1`/`SP-3`/`TS-3`, a narrow unstated `"lat,lon"` geo-spacing failure in `TS-2` (`0/15` vs `15/15`, sign/McNemar `p = 6.104e-05`), and confounds in `TS-1`.
- **Phase B (`raw_phase_b/`)**: `480` completions (`N = 5` runs/prompt × `6` prompts/suite across `PB-1`–`PB-6`, `0` errors):
  - `PB-1` (`xhigh`, `90` calls): Equalized `[P0|P1|P2|P3]` wording (`c5 = 30/30` in all arms; `flat_markdown` `0.972`, `flat_xml` `0.983` `p = 0.3632`, `nested_xml` `0.994` `p = 0.1019`).
  - `PB-2` (`xhigh`, `90` calls): `6/6` prompts flipped (`sign p = 0.0312`) on assertive superlatives (`0/30` on neutral examples); re-run strictly counterbalanced in `PC-1`.
  - `PB-3` (`xhigh`, `60` calls): Prospective memory under ~1,200-word noisy distractor logs (`30/30` ceiling in both arms).
  - `PB-4` (`xhigh`, `90` calls): `paired_affirmative` (`30/30`) beat `affirmative_only` (`14/30`, prompt `t(5) = 4.00, p = 0.0103`), while `bare_negative` (`27/30`) vs `affirmative_only` (`t(5) = 2.38, p = 0.0631`) was underpowered at `n = 6` -> re-run at `n = 16` in `PC-2`.
  - `PB-5` (`low`, `60` calls): `neutral_objective` (`29/30`, `TARa@5 = 83%`) vs `expert_persona` (`27/30`, `TARa@5 = 50%`, prompt `t(5) = -1.00, p = 0.3632`, underpowered null).
  - `PB-6` (`none`, `90` calls): Non-reasoning proxy (`reasoning_tokens = 0`): `rationale_first` `30/30` vs `11/30` for both `no_rationale` and `rationale_last` (prompt `t(5) = 3.12, p = 0.0261`).
- **Phase C (`raw_phase_c/`)**: `480` completions (`N = 5` runs/prompt × `16` prompts/suite at `high` effort, `0` errors):
  - `PC-1` (`240` calls): Counterbalanced `east`/`west` order (`50/50`); neutral & example arms hedged via parallel dual calls (`67/80`, `75/80`) or position 0 (`13/80`, `5/80`), choosing `second_tool` exclusively `0/80`. Assertive superlatives flipped exclusive selection of `second_tool` on `16/16` prompts (`80/80`: `40` east + `40` west, exact prompt sign `p = 3.052e-05`).
  - `PC-2` (`240` calls): Across `16` prompts / `4` clusters, `bare_negative` (`0.988`, `79/80`) and `paired_affirmative` (`0.950`, `76/80`) decisively beat unstated-blacklist `affirmative_only` (`0.650`, `52/80`: `t(15) = 4.06, p = 0.0010` and `t(15) = 3.87, p = 0.0015`). `paired_affirmative` vs `bare_negative` showed no advantage (`p = 0.3332`), resolving `C-01` (all `5` negative-arm misses were hyphenated compounds `consecutive-failure`).
