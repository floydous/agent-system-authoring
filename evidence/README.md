## Execution Metadata & Key Discovery

- **Target Models**: `GPT 6 Luna` (`4,378` benchmark records across Phases A–E & G + `490` Eval Suite v4 records + `85` Pi sessions; slug `cx/gpt-6-luna`), `Particle-1` (`950` `H-08` records; slug `openrouter/particle-ai/particle-1:free`), `Nemotron 3.5 Lightning` (`1,190` Phase F records; slug `openrouter/nvidia/nemotron-3.5-lightning:free`), and `Ling 3.2 Flash` (`1,510` Phase F records; slug `openrouter/inclusionai/ling-3.2-flash:free`) = **`8,028` total benchmark records** (`7,800` `N = 5` calls + `228` `N = 1` Phase A calls; see `source_checks.md` for router-slug vs. primary model-card provenance). *(Phase C `results_PC-1.jsonl`/`results_PC-2.jsonl` omitted `model`/`request_payload` in v1.1.0, fixed in `phase_c_harness.py`, Phases D–G, `H-08`, and Eval Suite v4.)*
- **Unit-of-Analysis, Multiplicity & Fixture Scope**: Zero pseudoreplication — repeated iterations (`N = 5`/prompt) are aggregated into prompt means (`df = P - 1`) before paired *t* or exact sign testing. Pooled run counts and `TARa@5` are reported descriptively. All `p`-values across `80+` reported contrasts are nominal (unadjusted for multiple testing): primary T2 findings hold under conservative correction (`p <= 1e-4` to `1e-33`), while borderline nominal contrasts (`0.01 < p < 0.05`, including `LING-PD4` `strict_all` `p=0.0179`, `LUNA-PG5` refresh `rtok` `p=0.0222`, `LUNA-PG4` latency `p=0.0290`, `PD-3` latency `p=0.0149`, and Pi post-slim `multi_provider_tools` vs. baseline `p=0.0476`) are exploratory. Pi real-agent permutation tests evaluate `N = 5` runs on `P = 1` fixed repo fixture per task (stochastic run variance, not cross-repo generalization).
- **Evaluator Scoring Notes**:
  - `PB-4` computes `length_ok` (`100 <= words <= 140`) descriptively but grades `constraint_pass` / `score` solely on forbidden-word and bold-markdown exclusions (`2` of `3` `affirmative_only` length misses still scored `1.0`).
  - `PC-2` prompts request `110-170` words while `phase_c_harness.py` grades `length_ok` with a buffered `100 <= words <= 185` window (`18` runs across arms fell outside `110-170` yet within `100-185`, yielding `80/80` `length_ok` everywhere).
  - `run_evals.py --rescore-only` (aliased `--rerender-only`) deterministically re-verifies all `210` trigger JSON outputs, `100` comparative generation lengths, `10` offline `comp_09` evaluations, raw response re-evaluation on `comp_01`/`comp_03`/`comp_04`, `comp_07` `8325c`/`18d` exact arithmetic, and all `100` raw judge JSON `dimension_scores` & delta invariants.
  - `recompute_stats.py` aggregates stored `metrics` dictionaries; full deterministic raw-response re-evaluation against harness evaluators runs in `tests/test_evidence_scripts.py`.
