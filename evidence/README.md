## Execution Metadata & Key Discovery

- **Target Models**: `GPT 6 Luna` (`3,098` benchmark records across Phases A–E + `490` Eval Suite v4 records; slug `cx/gpt-6-luna`), `Particle-1` / DeepSeek V4.1 Flash lineage (`950` `H-08` records; slug `openrouter/particle-ai/particle-1:free`), `Nemotron 3.5 Lightning` `30B-A3B` Mamba-2 SSM Hybrid (`1,190` Phase F records; slug `openrouter/nvidia/nemotron-3.5-lightning:free`), and `Ling 3.2 Flash` `~560B-A25B` Hybrid-Linear KDA+MLA MoE (`1,510` Phase F records; slug `openrouter/inclusionai/ling-3.2-flash:free`) = **`6,748` total benchmark records**. *(Phase C `results_PC-1.jsonl`/`results_PC-2.jsonl` omitted `model`/`request_payload` in v1.1.0, fixed in `phase_c_harness.py`, Phases D–F, `H-08`, and Eval Suite v4.)*
- **Unit-of-Analysis Policy**: Zero pseudoreplication — repeated iterations (`N = 5`/prompt) are aggregated into prompt means (`df = P - 1`) before paired *t* or exact sign testing. Pooled run counts and `TARa@5` are reported descriptively.
- **Evaluator Scoring Notes**:
  - `PB-4` computes `length_ok` (`100 <= words <= 140`) descriptively but grades `constraint_pass` / `score` solely on forbidden-word and bold-markdown exclusions (`2` of `3` `affirmative_only` length misses still scored `1.0`).
  - `PC-2` prompts request `110-170` words while `phase_c_harness.py` grades `length_ok` with a buffered `100 <= words <= 185` window (`18` runs across arms fell outside `110-170` yet within `100-185`, yielding `80/80` `length_ok` everywhere).
  - `run_evals.py --rescore-only` (aliased `--rerender-only`) re-aggregates and verifies `evals_results.md` from stored metrics in `results_evals_v4.jsonl`; future live runs also persist downstream probe `response_text`/`tool_calls` and per-dimension judge scores.

Revealed a latent prompt-wording defect in `SP-4` (`4/12` `c5_severity`), ceiling effects in `SP-1`/`SP-3`/`TS-3`, a narrow unstated `"lat,lon"` geo-spacing failure in `TS-2` (`0/15` vs `15/15`, sign/McNemar `p = 6.104e-05`), and confounds in `TS-1`.
